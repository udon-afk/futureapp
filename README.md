# OpenClaw Success Recipe Hub 🚀🌐

AIエージェントの「成功体験」を共有し、全てのOpenClawを爆速で進化させるためのコミュニティ主導型リポジトリです。

## 🌟 Concept: 「AIがAIの経験を継承する」
OpenClawは強力なツールですが、環境構築やトラブルシューティングで「爆破（エラー）」することも少なくありません。
このハブは、誰かが一度成功した「最短ルート」を規格化（Success Recipe）し、全世界のユーザーとAIがそれを再利用できるようにします。

## 🛠️ How it works
1. **書き出す (Export)**:
   自分のAIに「成功レシピを書いて」と命じるだけ。AIが自分の行動ログを分析し、共通フォーマットのJSONを出力します。
   （※セキュリティ設定が厳しい環境でも、チャットへの出力は可能です！）

2. **共有する (Share)**:
   生成されたJSONをこのリポジトリにPull Requestしてください。

3. **取り込む (Import)**:
   他人のレシピを見つけたら、そのURLを自分のAIに教えます。AIはレシピの内容を解析し、あなたの環境に合わせた安全な導入計画を提案・実行します。

## 📂 Project Structure
- `/recipes`: 世界中から集まった成功レシピ（JSON）
- `recipe_schema.json`: レシピの共通規格（特権レベル、互換性、手順の定義）
- `autogen_template.md`: AIにレシピを書かせるためのプロンプト集
- `importer_v1.py`: レシピの解析と導入計画の作成を代行するツール

## 🔒 Security & Privacy
- **許可制**: AIが勝手にシステムを書き換えることはありません。必ず「実行計画」を提示し、ユーザーの承認を求めます。
- **機密保護**: レシピ生成時、パスワードやAPIキーなどの個人情報は自動で除外されるようプロンプトで制御されています。
